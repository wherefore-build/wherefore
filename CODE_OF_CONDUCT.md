# Code of conduct

Wherefore follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), by
reference: its standards, its scope and its enforcement guidelines are this
project's, in every place the project is worked on or discussed.

To report behaviour that breaks it, write to hello@wherefore.build. Every
report is read, and kept confidential.
